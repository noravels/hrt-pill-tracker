# Android Mockup 001 — Calm Cards

A spacious Material-ish home screen focused on reassurance and a single next action.

## Design intent

- Calm, trustworthy medical tone with soft green surfaces and restrained accent color.
- Prioritizes the next dose and one clear "Mark dose taken" action.
- Shows schedules for Estradiol and an optional T-blocker without implying blockers are required.
- Explicitly communicates phase 1 local-only behavior: no account, device-stored plan, local reminders.

## Interaction included

Click "Mark dose taken" to change the button state and show a toast confirming the dose was recorded locally.

## Best fit

Good default direction if the Android phase 1 app should feel gentle, approachable, and low-cognitive-load for daily use.
