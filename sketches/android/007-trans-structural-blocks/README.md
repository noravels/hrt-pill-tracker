# Variant 007: Trans Structural Blocks

This revision responds to the feedback that the previous pass still felt like the trans theme was applied as a gradient skin, especially near the top.

## Direction

No soft gradient wash as the core identity. The transgender pride flag colors are used as structural UI blocks:

- blue left rail
- pink right rail
- vertical flag rail integrated into the dose card structure, not a top banner
- blue and pink section blocks
- selected states as solid blocks
- hard borders and offset shadows instead of glassy gradient cards

Official/common trans flag colors:

- Light blue: `#5BCEFA`
- Pink: `#F5A9B8`
- White: `#FFFFFF`

## Why this exists

The previous `006-trans-flag-native` design was more trans-themed than `004`, but still leaned on gradients. This one is more graphic, flatter, more product-system-like, and easier to translate to native Compose tokens.
