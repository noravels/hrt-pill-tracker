# Variant 006: Trans Flag Native

This is the stronger Claude Design pass after the previous page felt too generic and too subtle.

## Direction

Main theme: trans. The transgender pride flag is no longer a small accent; it is the visual structure of the product.

Official/common flag colors used:

- Light blue: `#5BCEFA`
- Pink: `#F5A9B8`
- White: `#FFFFFF`

## What changed

- The app chrome is built around the flag stripe rhythm.
- The next-dose card is a full trans-flag surface, not a generic card with a colored chip.
- Navigation active states use blue/pink identity gradients.
- The left design panel shows the flag and explicit product stance.
- The UI avoids streaks, stats, gamification, fake insights, and medical over-claims.
- The design is still Android Phase 1 compatible: Today, Setup, Routine, local-only privacy, mark-taken action.

## Why it is less generic

- Big typographic stance: “not a pastel habit app.”
- Strong flag composition instead of pastel background wash.
- Product-specific copy: local-only HRT tracker, fixed-anchor schedule, no streak pressure.
- CSS art and layout rhythm replace generic icon-card SaaS patterns.
